# KnitTrac — Процесс разработки (CONTRIBUTING)

## Git Flow
- Все коммиты идут в ветку `main`. Ветки для фич не создаются.
- Один коммит = одна логическая операция.
- Коммит пушится только после зеленых тестов (`./gradlew clean test`).
- Использование `git add .` запрещено, только явное перечисление файлов.
- Force-push только с `--force-with-lease` и явным разрешением.

## Pre-commit
- Настроен `pre-commit` хук через `.githooks`. Вызывает `gradlew test detekt`.
- Нельзя обходить через `--no-verify` без крайней необходимости.

## Работа с документацией
- KDoc на русском, парный.
- При изменении кода обновляется `HANDOVER.md` в том же коммите.
- Если сессия верификационная (без кода) — отдельный `docs(handover)` коммит.
